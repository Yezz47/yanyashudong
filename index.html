AI 产品经理作品集

研压树洞 · 产品说明

项目定位

面向研究生的 AI 情绪疏解 Web App，完成「场景识别 → 情绪命名 → 温和解释 → 低负担行动」的闭环。不是泛用聊天机器人，而是围绕研究生科研、导师、未来三类真实压力的专业陪伴工具。

边界：提供情绪支持，不替代心理咨询、精神科诊疗或紧急救助。高风险表达优先进入安全支持模式。

核心闭环

  1. 场景识别：自动判断科研 / 导师 / 未来，并内化年级信号（研一 → 科研先验，研三 → 未来先验）
  2. 情绪命名：咨询式陪伴，帮助用户辨认焦虑、委屈、自责、疲惫等情绪
  3. 温和解释：把“事情被评价”和“我整个人被否定”分开看
  4. 低负担行动：只给一个 10-15 分钟可完成的小动作，并允许用户不做

Prompt 迭代记录

v1（产品闭环驱动）：每 3 轮强制总结，节奏偏快，用户还没被充分安抚就被推进到行动。

v2（咨询式陪伴驱动）：先共情再澄清，每轮只问 1 个轻问题，约 5 轮一次轻柔回望，禁用元叙事词（“闭环”“模式”“识别结果”），用户侧只听到自然陪伴。

迭代依据：用户反馈“追问压迫感”偏高、“被理解感”不足。

指标体系

层级指标说明
北极星被理解感高分率反馈选“高”的占比，最代表核心价值
驱动闭环完成率 / 情绪改善度 / 行动采纳意愿衡量产品是否推动用户向前
健康安全触发率 / 兜底触发率 / 平均对话轮次反映稳定性与承接质量

反馈数据存储于本地浏览器（localStorage），可聚合、可跨会话对比 Prompt 版本。

关键产品决策

不在入口询问年级 / 年龄：洞察“年级隐含场景倾向”是对的，但焦虑用户对“被审问”敏感，前置问卷会造成抵抗心理。最终将年级信号内化为对话中的场景识别修正权重——既不增加负担，又让识别更准，守住“被听见”的核心体验。
